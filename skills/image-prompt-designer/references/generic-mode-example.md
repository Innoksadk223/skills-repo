# 通用模式文字示例（路线 A）

本例为构造的文字走查，不是参考图分析或独立模型评测；“用户确认”是示例条件，不代表真实用户已作出这些审美选择。示例 JSON 不写入真实风格库。规则以 `SKILL.md` 与 `generic-mode.md` 为准。

## 输入与关键确认

示例输入：“做一个通用风格。我不知道叫什么，想要安静，但不能全灰；像纸面，留白多一点，用一点红色醒神。不要固定乡村、天空之类的题材。”

候选理解：“你在意的是大面积低刺激的纸面与一个小而明确的视觉重点，而不只是‘极简’这个名字。红色可以是明亮醒目的，也可以偏暗、融入纸面；你希望哪种？这种配色和大留白是否以后换主题也保留？”

示例确认：“暖白纸面、暗红小面积点缀；这组颜色和单一重心、大留白都保留。纹理轻，边缘规整，不要固定重心在左还是右，不要发光和立体阴影。”

据此使用描述性名称“暖纸红点”，不声称它是某个公认流派。颜色、留白与单一重心成为可复用规则；题材、主体位置、动作等留给未来任务。已明确内容不重新逐组采访，也不为通用模板编造一个主体。

## 一份可整块复制的成品

```text
[风格规则]
轮廓边缘规整，用清楚的形状区分主体与背景。
暖白纸面带轻微纤维纹理，纹理不干扰主体轮廓。
底色：暖白。
强调色：暗红。
暖白为大面积底色，暗红只作小面积视觉强调。
各色块明度稳定，不用立体明暗塑形。
单一视觉重心，大面积留白；重心方向随任务调整。

[禁止事项]
不添加发光效果或立体投影。
不把纸张纹理铺得比主体更醒目。

[任务]
这是可复用风格模板，不包含具体画面任务。请另行提供主题、必要内容与用途约束；收到后应用以上规则创作。若任务必需的主体、动作或准确文字尚不明确，先询问，不自行编造。
```

“底色：暖白。”“强调色：暗红。”保留字段原值，后续一句明确面积关系；风格名不是成品能否表达清楚的前提。没有文字表现或模型参数要求，就不输出对应空节。真实使用时，块外仅简短报告必要限制与保存结果，不让用户拼接另一份负向清单。

## 复用后的本次覆盖

若之后加载本例风格，并明确要求“这次把暗红改成深蓝，其他不变，不更新源风格”：

- 仅替换颜色值与相应颜色用途规则；轮廓、纹理、照明、构图和负向规则保持原文与顺序。
- 检查禁项是否冲突；本例两条禁项无颜色限制，因此不变。
- 只生成本次提示词，报告“暗红 → 深蓝，源风格未改”，不新建变体。
- “本次改色”不是授权更新源文件；后续明确授权更新时，才修改相应字段。

本例展示的是筛选依据与覆盖边界，不把红色、纸张或留白当作所有任务的默认审美。
