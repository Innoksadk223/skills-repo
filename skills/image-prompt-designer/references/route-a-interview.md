# 路线 A：文字需求与聚焦确认

用于只有文字需求，或加载本地风格预填后的请求。先按 `SKILL.md` 的审美确认规则理解描述，不要求用户先知道风格名，也不先展示空模板。

## 十组覆盖检查

下表只供内部防漏，不是十轮问卷。可把相关缺口合并询问，不必展示整张表；无需填写所有字段。

| 检查组 | 按需检查的内容 |
| --- | --- |
| 输出目标 | 用途、受众、画面类型、目标模型、最终交付物 |
| 主体与动作 | 主体、动作、关系、姿态、表情、关键属性 |
| 背景 | 环境、地点、时间、天气、空间层次、背景元素及主体分离方式 |
| 视觉风格与媒介 | 时代、审美方向、写实程度、摄影、绘画或三维媒介 |
| 构图与画布 | 景别、视角、主体位置、留白、动势、方向、宽高比 |
| 光影和色调 | 主辅色及用途、明度、饱和度、色温、对比度、光源、光线方向与软硬、整体氛围 |
| 后期和纹理 | 成片处理、颗粒或噪点、清晰度、晕光、笔触、纸张、画布或材质表面质感 |
| 内容结构与文字 | 信息区块、叙事顺序、密度、文字语言、准确文案、可读性 |
| 符号或贴图与装饰 | 类型、功能、动作、位置、图案、符号、边框 |
| 负向约束与质量边界 | 禁止元素、风格冲突、常见结构缺陷、安全边界 |

维度边界：`主体与动作` 描述核心对象及行为，`背景` 描述环境与空间；`视觉风格与媒介` 定义整体审美，`后期和纹理` 定义成片处理与表面质感；最终颜色、明暗和照明效果归入 `光影和色调`，具体调色手法按需记入后期。

## 聚焦确认

1. 直接采用用户已经明确的内容与所选风格覆盖的条目；不复述求确认、不逐组重问。明显不适用的项跳过，并防止其重新进入成品。
2. 先找出会改变结果的审美分歧、必要任务内容和硬约束，合并本轮可独立回答的问题；依赖尚未作出的决定的问题留后。通常一轮解决，出现实质新分歧才继续，不设最低轮数或固定组数。
3. 有审美歧义时用少量可感知的效果对照确认；确需推荐时说明依据，不强制选择流派。色号、纹理强度等低影响细节按已确认方向处理，不逐项采访。
4. 必要时在对话内标注 `已明确`、`候选解释`、`授权推断`、`待补齐` 或 `不适用`。只有用户实际授权的范围才能标为授权推断；审美定调或笼统“你决定风格”不等于授权主体动作、姿态、正文和其他关键创作内容。非必要未知项保持未指定。
5. 具体任务的主体、正文、客户名、数据、背景、场景和动作进入最终提示词，不进入风格 JSON；多图逐图对应。通用风格模板不要求预先编造未来主体或场景，使用明确的下游任务输入约定。
6. 必要内容已明确、审美解释获确认且无高影响冲突后，返回 `SKILL.md` 组装。用户跳过采访但仍有关键缺口时说明缺口并暂停成品；只有用户要求时交付标为未确认的草稿，不保存、不把假设写成已确认。
