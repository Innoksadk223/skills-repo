# 生图提示词设计器

只生成可直接使用的生图提示词并维护本地 Markdown 视觉风格库，不直接生成图片；不倒推已粘贴的提示词文本。

## 边界

- 区分可复用视觉风格与单次画面内容：主体身份、单次背景、具体动作与准确文案仅写入单图提示词，不写入可复用风格文件。
- 画面与构图规则写成具体可见特征或“对象＋位置／动作＋遮挡或露出结果”（例如元素前后压盖、穿插位置、留白占比与明暗方向），不用“高级、独特、有空间感、有冲击力”等空泛评语代替规则。
- 提示词自包含，不引用当前对话、本技能或参考图文件。
- 默认输出模型无关的自然语言提示词；仅在用户指定目标模型时附加该模型可靠参数。

## 执行流程

1. **开场定界**
   - 确认输出形态（具体单图提示词／仅提炼可复用风格）、主题或风格方向（可选，可留空边选边定），以及是否指定已有本地风格或参考图。
   - 指定已有风格时，从 `~/.agents/image-prompt-styles/` 读取对应 `.md` 文件作为基线；用户本次明确改动仅覆盖冲突项，默认不改写原风格文件。

2. **仅文字输入**
   - 按下方五个模块逐块确认，每次只问一个模块，等用户答复后再进入下一模块。
   - 仅提炼可复用风格时跳过模块 1；已加载本地风格覆盖的内容直接采用，不重复确认。
   - 提问与候选选项保持风格中性，不预设单一流派；未指定或存在分歧时，顺着已定方向给出 2–3 个具体可感知的效果对照供选择，不展示术语清单。
   - 全部适用模块确认完毕后再输出最终提示词，不未问完直接生成。

3. **含参考图片**
   - 确认图片可读取；不可读取时停止并说明。
   - 按下方五个模块提取图中可见特征，区分可复用风格与原图一次性内容（主体、品牌、具体文案与单次场景），并标出无法从静图判断的待补齐项（如新图主体、目标用途、模型参数）；不把推测写成可见事实。
   - 一次展示提取结果与待补齐项；经用户核对、修正并补齐缺失项后再输出最终提示词。

## 五个规则模块

按以下五块逐项确认并组织最终提示词；以下条目均为中性询问维度，具体取向与禁止项由用户确定：

### 1. 【主体与画面内容】（仅具体单图适用）
- 核心主体、数量、姿态、动作与相互关系。
- 具体场景、环境、时段或天气。
- 画面内需要准确出现的文字原文与语言。

### 2. 【构图与空间关系】
- 画幅比例、景别与视角。
- 主体视觉重心、留白尺度与元素疏密。
- 前景、中景、背景的层叠、穿插、包围或遮挡关系（写成具体位置与可见结果）。

### 3. 【媒介、材质与纹理】
- 画面媒介：摄影、2D 插画、平面设计、3D 渲染、印刷品或混合媒介。
- 轮廓与边缘处理：无描边、硬边色块、手绘线稿或柔和过渡。
- 表面质感与后期：光滑、哑光、纸张／画布纹理、胶片颗粒、笔触、晕光或景深。

### 4. 【色彩与光影】
- 主底色、前景色、强调色与辅助色的色相、明度、饱和度及面积占比。
- 光源方向、光线软硬、明暗对比强弱与冷暖色温关系。
- 背景色彩与主体的分离方式。

### 5. 【文字、装饰与禁止项】
- 文字表现规则：无文字，或指定字体风格、排布位置与层级处理。
- 可复用装饰元素：符号、贴图、网格、边框、图案及其位置克制规则。
- 禁止事项：明确排除的风格、元素、材质或常见画面缺陷。
- 模型参数（仅指定模型时）：该模型确认可用的参数项。

## 本地风格库（Markdown）

- 存储路径：`~/.agents/image-prompt-styles/<kebab-case-id>.md`。
- 文件内容直接为可复制使用的纯 Markdown 风格提示词（仅含可复用规则，不含单次主体与业务文案），顶部简写风格名称与一句话说明，不再使用 JSON 格式。
- 新风格在用户确认后保存；复用已有风格时默认只读不改源文件，仅在用户明确要求更新或另存时写入。

## 组装输出

- 使用与用户相同的语言（除非另行指定），将已确认规则按对应模块组织为可直接复制的完整提示词。
- 仅提炼可复用风格时，末尾附下游任务接口：声明以上为通用视觉风格规则，使用前需另行提供主体、场景与准确文案，缺少关键内容时先询问，不自行编造。
- 写入或复用本地风格文件后，在提示词外注明文件路径。
