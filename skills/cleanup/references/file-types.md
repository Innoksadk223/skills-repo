# 分类边界

按用途判断，同一文件可有多种用途；存在长期用途时优先保留。本表不是自动删除清单。

| 类型 | 重点核实 |
|------|----------|
| 运行残留 | 是否仅为本次运行服务，是否仍被进程使用，是否承担诊断或恢复作用 |
| 结果制作工具 | 删除是否影响最终结果的运行、再生成或后续修改；是否已验收；是否在仓库或其他文件中被引用；“只运行过一次”不足以证明无用 |
| 验证与观察产物 | 是否属于交付证据、审查材料、性能基线或可复用测试的一部分 |
| 输入与中间材料 | 是否为唯一资料，原件是否实际保留，重新获取或转换是否可靠 |
| 任务状态与恢复资料 | 任务是否真正结束，是否仍支持恢复、追溯、协作或后续执行 |
| 备份与历史遗留 | 对应原件与版本是否明确，取代它的新版是否已验证可用，是否重复或已被替代，是否仍有独立恢复、审查或保留用途；是否依赖其他备份才能恢复 |

## 默认保护

- 最终产品、生成资源及运行、构建、部署所需内容。
- 正式测试、测试数据和长期验证工具。
- 用户原始材料、配置、数据库、凭据和依赖状态。
- 仍有价值的补丁、备份与审查、恢复资料；旧备份和冗余副本按正文规则核实，不永久豁免清理。

不因文件所在目录、命名方式、未跟踪状态或生成方式改变这些保护原则。敏感内容不要在报告中复述，也不要仅因含敏感信息就删除整份文件。

## 决策

按三档处理，与正文一致。

- **直接删**：本次运行产生、来源明确、用途已结束且不影响其他工作的临时残留。
- **验收后删**：结果已交付且用户已验收的一次性结果制作工具（且全库搜不到引用）；已被新版取代的旧备份（且新版已验证可用）；本次路径内确认无用的重复副本。用户尚未看到新结果时，对应的备份必须保留。
- **只列清单**：非本次生成的历史遗留、输入与中间材料、验证与观察产物、任务状态与恢复资料。归属或用途不确定时保留并说明原因。

用户此前已对相同清单授权的，不重复询问。
