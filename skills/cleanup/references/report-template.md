# Cleanup Report 模板

> 简单任务用一句话，复杂任务按此模板输出。

```
## Cleanup Report

### 已删除
- {文件/目录}: {原因（属于本次任务且不再需要）}
- ...
- 无（如无删除）

### 已修正
- {文件}: {修正了什么（如移除 debug 语句、密钥等）}
- ...

### 保留待确认
- {文件}: {原因（归属不明/用户可能需要/不确定）}
- ...
- 无（如无保留）

### 复查
- {命令/检查}: {结果，如 git status / git diff / ls / find}

### Status: cleaned | interrupted-cleaned
```

一句话报告也必须包含已删除、保留待确认及原因、Status；无则写"无"。
