# 清理报告

默认一行，交付末尾给出，说明删了什么、什么还等他确认。没有可删项写「无」，不要静默省略。

```
清理：删 3 项（本次运行残留 2、一次性脚本 1）；待确认 1 项（旧备份 build.bak/，新版已跑通、你还没看过页面）
清理：无
```

以下情况改用清单：

- 待确认项不止一条，或涉及备份、目录级差异、恢复链时。
- 本次删除了有回退价值的文件，需要说明依据。

清单内容只写这些：

- **已清理**：具体路径、档位与理由；没有则写“无”。
- **待确认**：拟删除的具体路径、类型、用途及删除影响；未获授权时明确标为保留。只列新增和仍未处理的，前几轮已列且没变化的归并一句。
- **保留**：需要特别说明的长期用途或归属疑问；整理备份时说明保留哪些版本及理由，拟全部删除时说明为何不再需要恢复副本。
- **复查**：目标路径和差异检查结果；有待确认项时不要声称已全部清理。

分类规则可以抽象，删除授权必须具体到路径。多个同类项可以合并说明用途，但不能用模糊目录范围代替清单。报告不复述敏感内容。
