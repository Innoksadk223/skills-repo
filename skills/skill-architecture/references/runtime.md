# 运行策略

## 首次运行

加载 SKILL.md -> 读模块清单 -> 按序加载 M1.md -> 检查 state/M1_* -> 不存在 -> 执行 -> 输出保存到 state/ -> 加载 M2.md -> ...

## 断点续跑

见 SKILL.md 原则2。示例流程：

```
M1: state/M1_*.json 存在 -> 跳过
M2: state/M2_*.md 存在 -> 跳过
M3: state/M3_* 不存在 -> 执行 M3
```

本次只跑 M3，token 节省 >60%。

## 失败重试

M3 失败 -> 读「回滚」段 -> 删除 `state/M3_*` -> 重新执行 M3。前置模块输出不受影响。

## 增量修改

用户："改第三章引言" -> 看模块清单 -> 引言在 M3 的 state 里 -> 直接加载 M3 -> 改引言 -> 更新 `state/M3_draft.md`。跳过 M1、M2，省 >70% token。
