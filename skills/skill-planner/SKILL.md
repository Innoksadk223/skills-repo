# Skill Planner

启动时的轻量路由器：只决定“要不要用 skill，以及先后顺序”。输出后立即执行，不把路由变成讨论。

## 快速流程

1. 看用户真正要完成什么
2. 扫描已注入的 skills / plugins / MCP 工具
3. 只选择会改变执行方式的能力
4. 按执行顺序输出路由，然后继续任务

## 输出格式

需要专项能力：

```
📋 任务路由
① skill-name → 本轮负责什么
② skill-name → 本轮负责什么
```

不需要专项能力：

```
📋 任务路由
无需专项 skill，直接执行
```

## 核心规则

- **少列**：只列必要项；“可能有用”不算必要。
- **必列**：用户点名的 skill、任务硬门槛、文件类型/领域强相关工具。
- **顺序**：外层流程先列，专业能力居中，验证/清理类放最后。
- **不等确认**：路由后直接开始；用户可随时纠正。
- **不展开解释**：必要项全部列出，每项一行；不为凑完整而补无关项。
- **不维护关键词表**：依靠当前可用能力和任务目标推理。

## 边界判断

- **无需专项 skill**：单步读文件、搜代码、查命令、解释概念。
- **需要专项 skill**：多步骤产物、代码修改、调试、评审、论文/PPT/表格/文档、联网核验、浏览器操作。
- **需求不清**：若目标或验收标准影响路线，先问一个具体问题；否则做合理假设并继续。

## 原则

路由是开工前的导航，不是计划书。准确优先，简短其次；能不列就不列，关键项不能漏。
