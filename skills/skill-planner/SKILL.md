# Skill Planner

超轻量 skill 路由器。每次任务启动时由 SOUL.md 自动加载。

## 流程

1. 阅读已注入 prompt 的可用 skills 列表
2. 判断当前任务是否需要 1+ 个专项 skill
3. 如需，推理最佳 skill 组合和执行顺序
4. 输出路由规划，然后立即开始执行任务

## 输出格式

复合任务（需要 1+ 个 skill）：

```
📋 任务路由
① skill-name → 一句话职责说明
② skill-name → 一句话职责说明
```

简单任务：

```
📋 任务路由
无需专项 skill，直接执行
```

## 核心规则

- **不阻塞** — 输出后直接开始执行，不等用户确认。用户看到后可随时纠正。
- **不惜错** — LLM 误判时用户纠正即可，不做置信度标注。
- **不维护列表** — 纯 LLM 推理，不依赖关键词映射或白名单。
- **不超一屏** — 最多 5 个 skill，每个一行。

## 边界判断

- 单步操作（读文件、搜代码、查命令）→ 无需专项 skill
- 解释询问（"这是什么""怎么用"）→ 无需专项 skill
- 复合任务（论文、PPT、审查、翻译、部署、调试）→ 必须规划

## 原则

宁可多列一个多余的 skill 让用户纠正，不可漏掉关键 skill 导致执行路径不对。
