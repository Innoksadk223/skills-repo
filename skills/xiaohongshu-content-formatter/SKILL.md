# 小红书内容格式化器

把用户提供的内容整理成统一的小红书图文格式。它是通用格式化技能，不为旅行、护肤、美食等品类预设固定写法。

## 处理原则

- 只使用用户提供或已经核实的信息，不补造经历、数据、效果、价格、口碑或使用感受。
- 信息较少时写得简洁，不用空话把正文强行拉长。只有缺失内容会导致误导时才提一个必要问题。
- 默认语气自然、具体、克制。可以适度强调真实优点，但不使用标题党、虚假悬念、绝对化承诺、制造焦虑或强迫互动。
- 标题、正文和图片必须围绕同一个核心信息，不能各说各话。
- 不套用品类模板；根据当次素材决定正文组织和图片数量。
- 用户明确给出标题、语气、图片数量、视觉风格或目标模型时，优先遵循。

## 工作流程

1. 提取主题、受众、已知事实、希望表达的态度、必须保留的内容和禁止项。
2. 先完成标题与正文，再按正文中的不同信息任务拆分图片。
3. 每张图片只承担一个主要任务；合并重复画面，避免为了凑数量生成近似图片。
4. 用户未指定数量时，使用能够完整表达内容的最少图片数，通常为 3–6 张。
5. 为每张图片输出完整、可单独复制的 Prompt，不使用“同上”“延续上一张”等外部引用。

## 文案要求

### 标题

- 只输出一个标题。
- 优先使用具体主题、真实场景或明确收益吸引阅读。
- 必要的强调必须有正文事实支撑。
- 避免“震惊”“封神”“闭眼冲”“错过后悔”“全网第一”等空泛或无法证明的表达。

### 正文

- 写成连贯、自然的小红书正文，不输出写作方法讲解。
- 保留真实细节、适用条件和必要限制；个人体验不能写成普遍事实。
- 分段和符号只服务阅读，不堆叠表情、感叹号或标签。
- 用户未要求时，不虚构品牌背书、促销信息、购买链接或互动口令。

## 图片与 Prompt 要求

每张图片先给出用途和画面文字，再给出 Prompt。Prompt 至少自包含：

- 图片用途与核心信息；
- 主体、场景和必要动作；
- 镜头、构图和文字安全区；
- 视觉风格、色彩与光线；
- 需要出现在画面中的准确文字；
- 与当张图片直接相关的禁止事项。

整组图片保持主体、色调、字体气质和版式逻辑一致，同时让全景、中景、近景或信息布局有所变化。生活类素材保留合理使用痕迹和自然光影；信息类图片优先保证层级与可读性。不要复刻具体创作者的独特设计。

若目标模型不擅长准确生成中文，在 Prompt 中要求预留清晰文字区，并将“画面文字”单独列出，方便后期排版；不得因此删掉用户需要的文字。

## 固定输出格式

严格使用以下结构，不增加写作教程或品类分析：

```markdown
## 标题
[一个标题]

## 正文
[可直接使用的正文]

## 配图与生图 Prompt

### 图 1｜[用途]
**画面文字：** [准确文字；没有则写“无”]

**Prompt：**
[完整、自包含、可单独复制的生图提示词]

### 图 2｜[用途]
**画面文字：** [准确文字；没有则写“无”]

**Prompt：**
[完整、自包含、可单独复制的生图提示词]
```

根据实际图片数量继续编号，不输出空图片项。

## 输出前检查

- 恰好一个标题，并且不靠夸张或虚假悬念吸引点击。
- 正文可直接使用，不包含写作过程、分析或未替换占位符。
- 所有事实有输入或核实依据，主观感受有清楚边界。
- 每张图对应正文中的一个信息任务，没有重复凑数。
- 每个 Prompt 都能脱离上下文单独使用，且包含准确画面文字。
- 整组图片风格统一，但构图和信息任务有变化。
