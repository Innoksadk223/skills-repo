# Image Prompt Designer 双路线流程设计

> 本次修订：审美确认、聚焦采访、单块输出与风格复用。以现存技能为基线更新；本文替代初版的采访预算、组装与验证约定，不用于从旧稿覆盖技能。

## 目标与文件边界

将自然描述或成品图片中的审美意图转译成可操作的生图提示词。保留具体任务与通用风格模式、文字与识图双路线及 schema v1；用户不必知道风格名，也能确认自己希望保留的视觉关系。

## 路线与审美确认

- 指定本地风格时先加载，再按输入选择路线；只有文字走 A，有成品图片或截图走 B。直接生图、实现界面或修改代码转交执行能力；不倒推粘贴的成品提示词文本。
- 只有明确声明通用风格时才采用通用模板；默认具体任务提示词。通用模式与路线正交。
- 共用过程：提取描述／观察证据 → 概括审美意图 → 必要时提出少量候选解释 → 用户确认或纠正 → 转译视觉规则。
- 区分整体感受、形成感受的可见特征、希望跨任务保留的核心。已有可靠风格名称仅作辅助；混合或自创审美使用描述性名称，不杜撰归属、不强行分类。
- 抽象感受落到形状、线条、色彩关系、明暗、材质、构图与密度等相关维度，不堆叠术语，不新增必填问卷。审美推断不授权编造主体、动作、姿态、正文或场景事件。

### 路线 A

保留十组作为内部覆盖检查，不规定轮数或提问顺序。已明确内容直接采用，不适用项跳过；合并会改变结果的审美分歧、必要任务内容和硬约束，用少量效果对照帮助选择。通常一轮解决，只有实质新分歧才继续；非必要未知项可留空。关键信息不足时暂停成品，不能用默认值冒充确认。

### 路线 B

仅基于实际可读取图片；不可读时停止，不伪造证据。分析阶段不提问，区分可见事实、候选解释和用户已确认偏好；用途、媒介来源或光源布置不能仅凭外观当作事实。静态截图也不能证明交互、响应式或技术实现。

拆分可复用风格、原图来源内容与目标任务内容。正常路径集中一次展示关键依据、审美理解、保留范围、冲突、必要缺口以及信息足够时的单块草稿，批量确认；不要求十行表全部填满，不转成逐组采访。具体任务内容须补齐；通用模板不预造未来主体。

确认或修正后均检查完整性、一致性、正负向冲突与保存范围。无新缺口则直接交付；出现新的关键缺口或互斥要求，说明最小阻塞项并暂停，请用户补齐或取舍，解决后再检查。确认次数不能凌驾于正确性。拒绝则停止，不保存未确认草稿。

## 单块输出契约

每份成品使用一个连续的 `text` 代码块，完整包含必要规则、任务、适用负向约束与可靠参数；不让用户拼接正向、负向和参数区域。

- 核心标题：`[风格规则]`、`[任务]`。
- 按需标题：`[内容规则]`、`[禁止事项]`、`[模型参数]`。没有内容整节省略，不写空栏目。
- 具体任务完整写入已确认的主题、主体、背景、动作、关系、准确文字和逐图要求；不能依赖当前对话或“见上文”。无文字任务不强加文案。
- 通用模式明确自己是风格模板，在 `[任务]` 内声明下游另需主题、必要内容和约束，缺关键输入时先询问；不冒充完整单图任务。
- 风格规则用可见关系表达，不靠角色设定、算力元指令或风格名堆叠。只为已指定模型添加可靠且匹配的参数。
- 多图同一任务可放一块；多份独立提示词一份一块，每份完整。
- 块外仅保留必要假设、限制、实际覆盖摘要和风格保存／复用路径或失败原因；证据与候选解释在确认阶段展示，不混入成品。

## 风格复用与保存

- 当前明确要求仅覆盖冲突条目及受影响禁项，未覆盖条目保留原文与相对顺序；不静默改写整个风格段。
- 加载风格后的本次覆盖或筛选默认不写源文件、不创建变体；只有明确更新或另存授权才持久化变化。
- 已确认且来源明确的新风格自动保存；同名不同内容沿用变体机制，未确认草稿和临时覆盖不作为新风格。
- 通用筛选依据用户希望跨任务保留什么。确认的配色、照明或构图可以是核心，不清空整类字段；剔除一次性内容与未经确认的场景安排。
- 保留 `schema_version: 1` 及现有全部字段，字段映射以主文件为准；风格不保存主体身份、正文、单次场景或识图证据。保存失败仍交付提示词并报告未保存。

## 验证与入口

1. 用可用文件工具或标准库检查 frontmatter、相对引用、旧规则残留、单块契约与字段兼容；schema 与修改前快照比较。不要假定存在未安装的校验脚本。
2. 少量文字样例覆盖自然描述、自创审美、通用模式保留配色／构图、具体任务完整性及已加载风格的本次覆盖；展示输入、关键确认、成品与判定依据。
3. 识图确认与修正用文字条件走查时，明确不是实际视觉测试；没有实际图片分析就没有识图证据。不得据此报告生图质量或模型理解率。
4. 所有验证不改真实风格库，不调用独立模型或实际生图；需扩展验证时另取授权。
5. 以独立快照保护未跟踪技能，核对无关工作区内容不变；保留现有正确链接，不运行全量安装器。最终还需用户检查单块复制与审美确认是否可用。
